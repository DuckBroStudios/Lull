# Lull

A simple, beautiful reminder app for Windows. Set reminders with titles,
descriptions, images, and times. When the time hits, a card floats above
every window you have open — including fullscreen games — until you dismiss
it or snooze for 5 minutes.

## Features

- Set reminders with title, description, optional image
- Floating alert above any window (yes, even fullscreen games)
- Custom chime sound
- Persistent storage — reminders survive restarts
- System tray icon — keeps running in the background
- Native Windows notifications

## Download

Grab the latest installer from the [Releases page](https://github.com/DuckBroStudios/lull/releases).

> Windows will warn that the publisher is unrecognized because the app
> isn't code-signed. Click "More info" → "Run anyway" to install.

## Built with

React, Electron, Tailwind, TypeScript.
